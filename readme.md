# 🚀 ForgeAI

### AI-Powered Multi-Agent Software Engineering Platform

ForgeAI is an AI-powered software engineering platform that leverages **Generative AI**, **Large Language Models (LLMs)**, and **n8n workflow orchestration** to automate the software development lifecycle.

Instead of relying on a single AI response, ForgeAI follows a **multi-agent architecture**, where specialized AI agents collaborate to transform a simple project idea into a structured software engineering blueprint.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/<username>/ForgeAI.git
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app:app --reload
```
